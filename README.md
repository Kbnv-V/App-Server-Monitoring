Программа клиент/сервер для мониторинга свободного места на диске и файлов с логами для сервера коробочного Битрикс24 на Alma Linux.
 
GetDisk.h, GetDisk.cpp, GetLog.h, GetLog.cpp, server.cpp - файлы, которые относятся к серверу
 
Menu.h, Menun.cpp, client.cpp - файлы, который относятся к клиенту
 
Программа управляется с клиента. 
Для работы программы нужно скомпилировать файлы для сервера и запустить их на фоне как демон, чтобы при закрытии консоли серверный демон продолжал работать.
Для включения служб мониторинга диска и файлов с логами нужно скомпилировать файлы для клиента и открыть исполняемый файл, далее следовать по меню.
 
Минимальное описание работы программы представлено в вордовском файле SERVER_MONITORING
В вордовском файле минимально описана работа программы и инструкция по сборке и запуску программы
